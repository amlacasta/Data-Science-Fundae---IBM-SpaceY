# Carpeta `data/`

Esta carpeta queda preparada para organizar los datos del proyecto si se desea trabajar localmente.

```text
data/
├── raw/        # datos originales descargados desde API, Wikipedia o recursos del curso
└── processed/  # datos limpios o transformados para análisis y modelado
```

En los notebooks originales, varios datasets se descargan directamente desde recursos remotos de IBM Skills Network o desde fuentes públicas. Por ese motivo, esta carpeta puede permanecer vacía.

No se incluyen datos confidenciales ni datos reales de una empresa.
